# Papertone

把 alphaXiv 的论文播客做成可以精听的资料库。

**在线访问：<https://gintmr.github.io/Papertone/>**

每篇论文都配了一段几分钟的对话式讲解。Papertone 把它们整理成卡片列表，
加上逐句时间轴与中英对照，用来练英语听力。

---

## 资料库

- 论文卡片：首页预览图、标题、作者、时长、主题标签
- 搜索论文标题或作者
- 按主题标签筛选
- 按收听状态筛选：全部 / 在听 / 已听完
- **继续收听**：自动定位到上次听到的位置

## 播放

- **波形进度条**，可直接拖动
- **逐句台词**，点任意一句跳到对应时间
- 当前句高亮并自动滚动；手动滚动台词时不会被拽回
- 播放速度 0.75× / 1× / 1.25× / 1.5×
- **定时停止**：15 / 30 / 45 / 60 分钟，或播完本集。到点音量渐弱再暂停

## 对照与听写

台词有四种显示模式，右上角切换：

| 模式 | 显示内容 |
|---|---|
| English | 只显示英文原稿 |
| Bilingual | 英文 + 中文译文 |
| Chinese | 只显示中文 |
| Dictation | 全部隐藏，点一句显示一句 |

## 其他

- 深色 / 浅色主题，右上角切换
- 手机端有常驻底部的迷你播放条
- 收听进度自动保存，下次打开接着听
- **可把资料库保存到本机**，之后离线也能听
- **访客统计**：资料库面板里可以看到匿名访问量、来源国家/地区和最近的访问记录

---

## 使用

1. 打开 <https://gintmr.github.io/Papertone/>
2. 点任意论文卡片开始播放
3. 想离线听：点右上角的同步图标 → **Save library to this device**

> 同步面板里的 `Scan` / `Import` 是维护资料库用的，日常收听不需要用到。

## 数据来源

- 论文与播客音频来自 [alphaXiv](https://www.alphaxiv.org/)
- 台词来自 alphaXiv 的官方文稿，时间轴由自动对齐生成
- 中文译文由机器翻译，仅供理解参考

音频不随本站分发，播放时直接读取 alphaXiv 的 CDN。卡片和播放器里的链接
都指向 [alphaXiv](https://www.alphaxiv.org/) 上的对应论文页面。
